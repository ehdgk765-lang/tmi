일정 관리

일정 등록

관리자

캘린더에서 날짜를 터치하면 일정 등록 화면이 나타납니다.

  1. 캘린더에서 원하는 날짜를 터치합니다.
  2. 일정 제목, 시작/종료 시간을 입력합니다.
  3. 참석 인원 제한(전체/남/여)을 설정합니다.
  4. 코트 정보, 호스트, 색상 등을 지정합니다.
  5. "등록" 버튼을 눌러 저장합니다.
호스트로 지정된 멤버는 해당 일정에서 생성한 대진표를 직접 편집할 수 있습니다.

일정 수정 / 삭제

관리자

등록된 일정을 터치하면 상세 화면에서 수정하거나 삭제할 수 있습니다.

  • 일정 제목, 시간, 인원 제한 등 모든 항목 수정 가능
  • 일정 삭제 시 확인 팝업이 표시됩니다
  • 정산 정보(코트비, 공 종류, 게스트 수 등) 입력 가능

대관 엑셀 업로드

관리자

코트 대관 엑셀 파일을 업로드하여 일정을 일괄 등록할 수 있습니다.

  1. 캘린더 상단의 업로드 아이콘을 터치합니다.
  2. 엑셀 파일(.xlsx)을 선택합니다.
  3. 현재 월에 해당하는 시트가 자동 인식됩니다.
  4. 주차별 등록/해제를 선택하여 일정을 생성합니다.

일정 공유하기

공통

일정 상세 화면에서 공유 링크를 생성하여 멤버들에게 전달할 수 있습니다. 링크를 받은 멤버가 접속하면 해당 일정으로 바로 이동합니다.

참고: 삭제된 일정의 공유 링크로 접속하면 자동으로 기본 화면으로 이동됩니다.
👥
멤버 관리

멤버 등록

관리자

"멤버 관리" 탭에서 클럽 멤버를 등록하고 관리합니다.

  1. 이름을 입력하고 성별(남/여)을 선택합니다.
  2. "추가" 버튼을 눌러 등록합니다.
엑셀 업로드: 이름, 성별 컬럼이 포함된 엑셀 파일(.xlsx, .csv)을 업로드하면 멤버를 일괄 등록할 수 있습니다. 중복 이름은 자동으로 건너뜁니다.

멤버 수정 / 삭제

관리자
  • 이름 수정: 멤버 이름을 터치하면 수정 모드로 전환됩니다
  • 성별 변경: 남/여 배지를 터치하면 토글됩니다
  • 삭제: 개별 삭제 또는 체크박스로 여러 명 일괄 삭제 가능
  • 검색: 이름 입력란에 검색어를 입력하면 실시간 필터링 (한글 초성 검색 지원)

회원 관리 (상세)

관리자

사이드 메뉴의 "회원 관리"에서 상세 회원 정보를 관리합니다.

  • 회원 유형: 정회원 / 게스트 구분 설정
  • 참석 빈도: 주1회(토) / 주1회(일) / 주2회 설정
  • 조 배정: 멤버를 그룹(조)에 배정
  • 회비 관리: 월별 납부 현황 관리 (12개월 그리드)
  • 메모: 회비 셀을 길게 누르면 메모를 입력할 수 있습니다

조(그룹) 관리

관리자

"회원 관리" > "조 관리" 탭에서 그룹을 만들고 멤버를 배정합니다.

  • 조 이름과 요일을 지정하여 새 그룹 생성
  • 그룹별 멤버 추가/제거
  • 그룹 이름 수정 (인라인 편집)
  • 그룹 삭제
🏆
대진표 관리

대진표 자동 생성

관리자

"대진표 작성" 탭에서 대진표를 자동 생성합니다.

  1. 대진표 이름을 입력합니다.
  2. 경기 방식을 선택합니다:
      - 남자 복식(MD), 여자 복식(WD), 혼합 복식(XD), 남자 단식(MS), 여자 단식(WS), 자유 복식(FD)
  3. 참여할 멤버를 체크하여 선택합니다.
  4. 세트 수(1/3/5세트)를 설정합니다.
  5. "생성" 버튼을 누르면 자동으로 대진이 편성됩니다.
팀이 중복되지 않도록 자동 배치됩니다. 참여 인원에 따라 여러 라운드(시간대)로 나뉩니다.

대진표 편집

관리자 호스트

생성된 대진표에서 다양한 편집이 가능합니다.

  • 대진표 이름 수정: 제목을 터치하여 변경
  • 멤버 교체: 매치 내 멤버를 터치하면 다른 멤버로 교체 가능
  • 매치 추가: 라운드에 새 매치를 추가
  • 매치 삭제: 불필요한 매치 제거
  • 매치 순서 변경: 드래그하여 매치 순서 조정
  • 경기 방식 변경: 대진표 전체 경기 방식 변경
호스트 편집 권한: 일정에서 호스트로 지정된 멤버도 해당 일정의 대진표를 편집할 수 있습니다.

커스텀 대진표 (토너먼트/리그)

관리자

"대회 만들기" 탭에서 토너먼트 또는 리그 형식의 대진표를 만듭니다.

토너먼트 (싱글 엘리미네이션):

  • 4, 8, 16, 32강 브래킷 지원
  • 단식/복식 모두 지원
  • 멤버를 수동으로 원하는 위치에 배치
  • BYE(부전승) 자동 처리

리그 (라운드 로빈):

  • 참가자 전원 라운드 로빈 방식
  • 자동 순위표 (승/무/패, 승점, 포인트)
  • 라운드별 경기 일정 자동 생성

대진표 삭제

관리자 호스트

"대진표" 탭의 카드 목록에서 삭제 버튼을 눌러 대진표를 삭제할 수 있습니다. 삭제 전 확인 팝업이 표시됩니다.

🎾
스코어 입력

경기 스코어 입력 / 수정

공통
  1. 대진표에서 경기 카드의 스코어 영역을 터치합니다.
  2. 세트별 점수를 입력합니다 (세트 수는 대진표 설정에 따름).
  3. "저장" 버튼을 눌러 스코어를 기록합니다.
관리자: 모든 경기의 스코어를 입력/수정할 수 있습니다.
멤버: 본인이 참여한 경기의 스코어만 입력할 수 있습니다.
📊
통계

통계 조회

공통

"통계" 탭에서 다양한 통계를 확인할 수 있습니다.

  • 월별 통계: 선택한 월의 메달 랭킹(금/은/동)과 개인 전적
  • 전체 통계: 누적 메달 랭킹과 전체 전적
  • 조별 통계: 그룹별 순위, 멤버별 성적
  • 성별 필터: 전체 / 남자 / 여자별 조회

표시되는 지표: 경기 수, 승/패/무, 승점, 포인트, 경기 유형별(MS/WS/MD/WD/XD/FD) 전적

💰
정산

정산 현황

관리자

사이드 메뉴의 "정산"에서 일정별 비용 정산 내역을 확인합니다.

  • 호스트별 요약: 호스트명, 주최 횟수, 총 코트비, 총 청구 금액
  • 월별 일정 목록: 각 일정의 상세 정산 정보 (코트비, 공 종류/수량, 게스트 수)
  • 월별로 접고 펼칠 수 있는 카드형 UI

다크 모드

공통

헤더 우측 상단의 해/달 아이콘을 터치하면 라이트/다크 모드를 전환할 수 있습니다. 설정은 기기에 저장되어 다음 접속 시에도 유지됩니다.

기기의 OS 다크모드 설정에 따라 자동으로 적용되며, 수동으로 변경할 수도 있습니다.

홈 화면에 추가 (PWA)

공통

앱을 홈 화면에 추가하면 일반 앱처럼 바로 실행할 수 있습니다.

iOS (Safari):

  1. Safari에서 앱에 접속합니다.
  2. 하단 공유 버튼을 터치합니다.
  3. "홈 화면에 추가"를 선택합니다.

Android (Chrome):

  1. Chrome에서 앱에 접속합니다.
  2. 설치 배너가 나타나면 "설치"를 터치합니다.
  3. 또는 메뉴 > "홈 화면에 추가"를 선택합니다.

로그인

일정

일정 확인

"일정" 탭의 캘린더에서 등록된 일정을 확인할 수 있습니다.

  • 날짜에 표시된 색상 라벨을 터치하면 일정 상세를 볼 수 있습니다
  • 좌우 화살표로 월 이동이 가능합니다
  • 일정 상세에서 시간, 장소, 참석자 목록을 확인할 수 있습니다

참석 입력

  1. 캘린더에서 일정을 터치하여 상세 화면을 엽니다.
  2. "참석" 버튼을 눌러 참석을 등록합니다.
  3. 참석을 취소하려면 본인 이름 옆의 취소를 터치합니다.
인원 제한이 있는 일정에서 정원이 찬 경우 대기열에 등록됩니다. 다른 멤버가 취소하면 자동으로 참석 처리됩니다.
🏆
대진표

대진표 보기

"대진표" 탭에서 진행 중인 대진표를 확인합니다.

  • 대진표 카드를 터치하면 상세 대진표가 표시됩니다
  • 본인이 참여한 경기는 파란색 하이라이트로 표시됩니다
  • 라운드(시간대)별로 경기가 구분되어 표시됩니다
  • 토너먼트 형식은 브래킷(대진) 그래프로 표시됩니다
  • 리그 형식은 순위표와 라운드별 경기 목록으로 표시됩니다

호스트 편집 권한

호스트

일정의 호스트로 지정된 경우, 해당 일정에서 만든 대진표를 편집할 수 있습니다.

  • 대진표 이름 수정
  • 멤버 교체 (다른 멤버로 변경)
  • 매치 추가/삭제
  • 매치 순서 변경 (드래그)
  • 경기 방식 변경
  • 모든 경기 스코어 입력
호스트 지정은 관리자가 일정 등록 시 설정합니다. 호스트 여부는 일정 상세에서 확인할 수 있습니다.
🎾
스코어 입력

내 경기 스코어 입력

  1. 대진표에서 본인이 참여한 경기를 찾습니다 (파란색 하이라이트).
  2. 경기 카드의 스코어 영역을 터치합니다.
  3. 세트별 점수를 입력합니다.
  4. "저장" 버튼을 눌러 기록합니다.
참고: 본인이 참여하지 않은 경기의 스코어는 입력할 수 없습니다. 수정이 필요한 경우 관리자 또는 호스트에게 요청하세요.
📊
통계

내 전적 확인

"통계" 탭에서 개인 전적과 클럽 랭킹을 확인합니다.

  • 월별 통계: 이번 달 메달(금/은/동) 수와 전적
  • 전체 통계: 누적 성적과 순위
  • 조별 통계: 소속 조의 순위와 멤버별 성적
  • 본인 이름은 목록에서 하이라이트되어 쉽게 찾을 수 있습니다

확인 가능한 지표: 경기 수, 승/패/무, 승점, 포인트, 경기 유형별 전적
